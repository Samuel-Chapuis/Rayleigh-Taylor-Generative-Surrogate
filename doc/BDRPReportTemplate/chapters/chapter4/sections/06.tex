\subsection{Wavelet-based generative framework}

\subsubsection{Wavelet representation of RTI fields}

The wavelet pipeline begins with the preprocessing of the RTI dataset. The raw
density fields are first loaded from the simulation files and preprocessed
using the existing data augmentation routines. A two-dimensional discrete
wavelet transform is then applied to each image using a Daubechies-1 basis.

For a decomposition level $j$, each field is mapped to four coefficient maps:
the approximation sub-band $LL$ and the three directional detail sub-bands
$LH$, $HL$, and $HH$. In the implementation,
these four arrays are stacked into a tensor of shape $(N,4,H',W')$, where $N$
is the number of samples and $(H',W')$ is the spatial size of the wavelet
coefficients at the chosen level. The dataset is then split into training,
validation, and test subsets, and each split is saved independently as a PyTorch
tensor.

This representation preserves the most relevant multi-scale information while
reducing the learning problem to a structured tensor prediction task. In
practice, the decomposition also makes the notion of coarse-to-fine generation
explicit: the approximation channel plays the role of a low-frequency prior,
while the three detail channels contain the higher-frequency content that must
be synthesized.

\subsubsection{Conditional diffusion on wavelet coefficients}

The training data are loaded from the precomputed tensors and normalized
channel by channel using the statistics of the training split. This
normalization is important because the four wavelet channels do not share the
same numerical scale and would otherwise contribute unevenly to the
optimization process.

The model uses a conditional Wavelet Score-based Generative Model (WSGM)
structure, following the coarse-to-fine factorization principle of
\citet{Guth2022WSGM}. The input to the U-Net is composed of the approximation
channel concatenated with the noisy detail channels. The network predicts the
selected SGM target associated with the noised detail coefficients, which means
that generation is guided by the coarse-scale information rather than being
unconditional. In other words, the model learns how to reconstruct the missing
fine-scale structure given the large-scale wavelet content.

The corresponding architecture is deliberately compact. The U-Net receives
four input channels in total, with one channel reserved for the prior
information and three channels corresponding to the target detail maps. The
network depth and the number of blocks per level remain modest so that training
is compatible with the size of the available RTI dataset. The diffusion
schedule itself follows the same principle as the image-space SGM, with a
continuous VP-SDE controlled by an affine noise schedule between
\texttt{beta\_min} and \texttt{beta\_max}.

During training, the loss is again a mean squared error between the true SGM
target and the target predicted by the network. The model therefore learns a
conditional score model for the wavelet detail coefficients. Once training is
complete, the checkpoint and the preprocessing statistics are stored in a
configuration file so that sampling can be reproduced later without ambiguity.
The conditioning and noising structure of this loop is shown in
Figure~\ref{fig:conditioned_training_loop}.

At a given wavelet level, let $LL$ denote the approximation channel and
$D_0=(LH,HL,HH)$ the three detail channels. The approximation channel is
used only as a condition, whereas the VP-SDE is applied to the detail tensor.
With the same notation as the image-space SGM, the exact conditional noising
marginal is
\[
    D_t
    =
    \sqrt{\bar{\alpha}(t)}\,D_0
    +
    \sigma(t)\epsilon,
    \qquad
    \sigma(t)=\sqrt{1-\bar{\alpha}(t)}.
\]
The baseline WSGM training procedure is therefore:
\begin{algorithm}[H]
\caption{Conditional WSGM training procedure at wavelet level $j$}
\begin{algorithmic}
\STATE Load precomputed wavelet tensors $(LL,LH,HL,HH)$ for level $j$.
\STATE Normalize each coefficient channel using training-split statistics.
\STATE Set $D_0=(LH,HL,HH)$ and keep $LL$ fixed as the conditioning field.
\STATE Initialize a conditional WSGM with a time-conditioned U-Net and the same affine VP-SDE schedule as the baseline SGM.
\FOR{each training epoch}
    \FOR{each batch $(LL,D_0)$}
        \STATE Sample a continuous time $t\in[\varepsilon_{\mathrm{time}},\mathds{1}]$ and Gaussian noise $\epsilon$ with the shape of $D_0$.
        \STATE Compute $\bar{\alpha}(t)=\exp(-\int_0^t\beta(s)\,ds)$ and $\sigma(t)=\sqrt{1-\bar{\alpha}(t)}$.
        \STATE Build the noisy details $D_t=\sqrt{\bar{\alpha}(t)}D_0+\sigma(t)\epsilon$.
        \STATE Build the target $y_t=\epsilon$ for \texttt{epsilon}-prediction or $y_t=\sqrt{\bar{\alpha}(t)}\epsilon-\sigma(t)D_0$ for \texttt{v}-prediction.
        \STATE Predict $\hat{y}_\theta(LL,D_t,t)$ from the concatenated tensor $(LL,D_t)$.
        \STATE Minimize $\|y_t-\hat{y}_\theta(LL,D_t,t)\|_2^2$.
    \ENDFOR
    \STATE Compute validation loss and save the checkpoint if it improves.
\ENDFOR
\end{algorithmic}
\end{algorithm}

Sampling uses the same probability-flow ODE as the baseline SGM, but only in
the detail subspace and conditionally on the fixed approximation channel. The
score estimate is
\[
    s_\theta(D_t,t\mid LL)
    =
    -\frac{\hat{\epsilon}_\theta(LL,D_t,t)}{\sigma(t)}.
\]
The conditional WSGM sampling procedure is:
\begin{algorithm}[H]
\caption{Conditional WSGM sampling procedure at wavelet level $j$}
\begin{algorithmic}
\STATE Reload the WSGM checkpoint and the coefficient normalization statistics.
\STATE Select or generate an approximation channel $LL$ and normalize it.
\STATE Sample $D_{\mathds{1}}\sim\mathcal{N}(0,I)$ with three detail channels and the spatial shape of $LL$.
\STATE Choose $N_{\mathrm{step}}$ integration steps, $\Delta t=-(\mathds{1}-\varepsilon_{\mathrm{time}})/N_{\mathrm{step}}$, and a solver, Heun by default.
\FOR{$i=0,\ldots,N_{\mathrm{step}}-1$}
    \STATE Set $t_i=\mathds{1}+i\Delta t$ and $t_{i+1}=t_i+\Delta t$.
    \STATE Reconstruct $\hat{\epsilon}_\theta(LL,D_{t_i},t_i)$ from the network output.
    \STATE Compute $s_\theta(D_{t_i},t_i\mid LL)=-\hat{\epsilon}_\theta(LL,D_{t_i},t_i)/\sigma(t_i)$.
    \STATE Compute the conditional probability-flow drift
    \[
        F_\theta(D_{t_i},t_i\mid LL)
        =
        -\frac{1}{2}\beta(t_i)D_{t_i}
        -\frac{1}{2}\beta(t_i)s_\theta(D_{t_i},t_i\mid LL).
    \]
    \STATE Predictor step: $\widetilde{D}=D_{t_i}+\Delta t\,F_\theta(D_{t_i},t_i\mid LL)$.
    \IF{Heun solver is used}
        \STATE Compute $F_\theta(\widetilde{D},t_{i+1}\mid LL)$ and set
        \[
            D_{t_{i+1}}
            =
            D_{t_i}
            +
            \frac{\Delta t}{2}
            \left[
            F_\theta(D_{t_i},t_i\mid LL)
            +
            F_\theta(\widetilde{D},t_{i+1}\mid LL)
            \right].
        \]
    \ELSE
        \STATE Set $D_{t_{i+1}}=\widetilde{D}$.
    \ENDIF
\ENDFOR
\STATE Denormalize the generated details and concatenate them with the physical $LL$.
\STATE Apply the inverse discrete wavelet transform to obtain the finer-scale field.
\end{algorithmic}
\end{algorithm}
